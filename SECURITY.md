# Security

Supported version: 0.1.x. The tool does not repair, install, execute compilers or upload reports.

For non-sensitive bugs, open a GitHub issue with a minimal synthetic reproduction. Never attach real environment dumps, private paths, credentials, serial numbers, or unreviewed system logs. For sensitive vulnerabilities, use GitHub's private vulnerability reporting if available; otherwise open an issue requesting a private contact without disclosing exploit details or sensitive data.

Native tools and local filesystem state are trusted. This is not a sandbox, malware detector or integrity verifier. Interrupted or failed native probes are not proof of an absent installation.
